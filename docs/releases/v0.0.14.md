# v0.0.14 —— 修复「结束不了 KOOK 进程」与「启动不了 KOOK」

这一版只做一件事：把退出/启动这条链路上的三个缺陷修掉。它们单独看都像小问题，串起来就是一个死循环——**进程退不掉，然后退不掉的进程让下次启动没反应**。

基线：官方 PC `0.112.0` / `c5af713-kook_3321`，仅 x86_64。

---

## 现象与根因

### ① 结束不了 KOOK 进程

**现象**：`kill`、`Ctrl+C`、注销会话都杀不掉，只能 `kill -9`。

**根因**：退出拦截只认托盘菜单。「关闭时最小化到托盘」的 `preventDefault()` 挂在窗口 `close` 上，而放行开关 `quitForReal` 只在托盘菜单点「退出」时才置真。SIGTERM、会话注销、系统级 `app.quit()` 都会走同一段 `close`，全部被拦下，`app.quit()` 于是永远中止。

**修法**：监听 `before-quit`（所有退出路径的必经之地）置真，并显式处理 `SIGTERM` / `SIGINT` / `SIGHUP`；信号回调里加 3 秒兜底 `app.exit(0)`，防止某个渲染进程卡在 `beforeunload` 上把退出拖住。

### ② 启动不了 KOOK（双击图标没有任何反应）

**现象**：双击图标，进程起来又立刻消失，界面不出现。

**根因**：主窗口关闭后，覆盖层等其它 `BrowserWindow` 还活着，`window-all-closed` 不触发，进程留了下来并攥着单实例锁。下次启动时 `requestSingleInstanceLock()` 失败，新进程直接 `exit(0)`；旧进程那边窗口已经销毁，`second-instance` 里无事可做——点击被静默吞掉。

**修法**：主窗口 `closed` 时确保 `app.quit()`，不再留残留进程；`second-instance` 发现主窗口已销毁时 `app.relaunch()`，而不是什么都不做。

### ③ 最小化后点托盘唤不回

**修法**：`show()` 不会取消最小化状态，先 `restore()` 再 `show()`。托盘点击、「显示 KOOK」菜单、二次启动三处统一走同一个 `showMainWindow()`。

### 附带：没有托盘宿主时不再把窗口藏起来

GNOME 默认没有 `org.kde.StatusNotifierWatcher`，但 `new Tray()` 依然构造成功——图标不显示。此时「关闭到托盘」等于把窗口藏进一个打不开的地方。现在先探测宿主是否存在，不存在就不做拦截，关闭按钮直接退出。

## 下载

> Gitee 单附件上限 100MB，安装包本体超过这个限制，所以在这里以 **7z 分卷**提供。
> 三个包合计 560MB，分卷后每个不超过 95MB。

| 格式 | 分卷文件 | 解压后大小 |
|---|---|---:|
| AppImage | `KOOK-0.0.14-x86_64.AppImage.7z.001/.002/.003` | 236,106,041 |
| deb | `kook_0.0.14_amd64.deb.7z.001/.002` | 166,781,338 |
| rpm | `kook-linux-0.0.14.x86_64.rpm.7z.001/.002` | 186,244,048 |

**合并与校验**（以 AppImage 为例，只需指定第一个分卷）：

```bash
7z x KOOK-0.0.14-x86_64.AppImage.7z.001     # 自动合并 001/002/003
chmod +x KOOK-0.0.14-x86_64.AppImage
sha256sum KOOK-0.0.14-x86_64.AppImage        # 应为 e8d46593…3d67
```

没有 `7z` 时：Debian/Ubuntu `sudo apt install p7zip-full`，Fedora `sudo dnf install p7zip`，Arch `sudo pacman -S p7zip`。

**完整原文（含未分卷的整包）**：[GitHub Releases v0.0.14](https://github.com/kanniganfan/kook-linux/releases/tag/v0.0.14)

## 安装

**AppImage**：

```bash
chmod +x KOOK-0.0.14-x86_64.AppImage
./KOOK-0.0.14-x86_64.AppImage
```

**deb**：

```bash
sudo apt install ./kook_0.0.14_amd64.deb
```

**rpm**：

```bash
sudo dnf install ./kook-linux-0.0.14.x86_64.rpm
```

覆盖安装即可，不需要先卸载旧版。

## 如果你正卡在「启动不了」

```bash
pkill -9 -f kook-linux-bin
rm -f ~/.config/KOOK/Singleton*
```

## 已知限制

- **没有系统密钥环时会丢掉「记住登录」**：装 `gnome-keyring` 或 `kwallet` 后恢复。
- **托盘图标依赖桌面扩展**：GNOME 需 AppIndicator 扩展，否则不显示托盘，此时关闭按钮直接退出。
- **Wayland 全局覆盖层**：需要 X11 会话。
- **仅 x86_64**：没有 ARM 真机验证。
